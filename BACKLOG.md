# Бэклог проекта

Единственный источник очереди, требований, критериев приёмки и статусов —
[GitHub Issues](https://github.com/albazrov/reminder_bot/issues).
Не добавляйте задачи в этот файл: создавайте issue после проверки дублей.
В PR указывайте связанные issues; закрывайте их после проверки всех
критериев и слияния реализации, а не только по наличию похожей функции.
