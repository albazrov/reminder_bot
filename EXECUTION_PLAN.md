обновление Excel — опубликован в
[PR #18, dev → test](https://github.com/albazrov/reminder_bot/pull/18)
слит: test merge `d0c7bb4`. Для исправленного commit `68cfb6b`
[CI и test deploy](https://github.com/albazrov/reminder_bot/actions/runs/42747221751)
прошли. Повторный Greptile: 21 файл, 0 новых замечаний; оба thread resolved.
Два подтверждённых замечания Greptile исправлены: локальное дополнение
привязок к новым утверждённым задачам и повторы asyncio-таймаутов
на Python 3.10. Личный экран перечитывает привязки после загрузчика.
Слит [PR #19, test → main](https://github.com/albazrov/reminder_bot/pull/19).
Его дополнительное замечание Greptile воспроизведено и исправлено в `test`:
смена checksum/size при скачивании повторяется в рамках общего бюджета,
а ошибки проверки workbook по-прежнему завершаются сразу.
Дополнительная регрессия защищает от публикации отвергнутых байтов,
когда повторная metadata снова соответствует прежнему кэшу:
содержимое перечитывается и проверяется у выбранного файла.

21 файл, 0 новых замечаний, оба thread resolved.
Пользовательские правила описаны в руководствах и README, а не
дублируются в очереди незавершённых требований.
Production-workflow после слияния в `main` завершился успешно.

### Этап 2 — точная административная «Сводка»

Реализован локально в `dev`: текущий/следующий месяц по фактической
дате задачи, конкретные даты отправки в часовом поясе бота, замены,
причины пропуска, ответы и отметки доставки. Используются только
утверждённые планы SQLite; просмотр не меняет назначения, настройки,
ответы и доставки и не загружает Excel.
Условия доступности отправки разделяются с реальным обработчиком.
Добавлены листание, обновление, проверки прав и устаревших кнопок.
Проверки: целевой набор — 253 теста OK, 5 пропущено; финальный полный
набор — 805 тестов OK, 11 пропущено на macOS. `compileall` и
`git diff --check` прошли. Прогноз сопоставлен с реальным обработчиком
на общих mock-данных; живые сообщения не отправлялись.
Этап подготовлен к публикации отдельным PR `dev → test`.
Результаты CI, test deploy и Greptile проверяются на окончательном head PR.
