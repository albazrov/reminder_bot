## Разработка в `dev` и проверка в `test`

Реализованы блокировка отправки групповых и личных напоминаний и месячной
сводки без утверждённого графика; личная сводка для администраторов
показывает ответственных с включёнными уведомлениями и время отправки.
Ошибки подготовки личного напоминания записываются в журнал без отдельного
сообщения админу служения. Также добавлены быстрый вход «🔔 Напомнить» из
карточки, порядок «старший» перед участниками смены и повторы загрузки
Excel из настроек Яндекс.Диска с уведомлением о сбое только суперадминам
после исчерпания попыток.

Проверяемый PR: [#15, dev → test](https://github.com/albazrov/reminder_bot/pull/15).
Для исходного commit `7107bbf` CI и test deploy прошли; ручная приёмка
не подтверждена. PR не слит, в prod эти изменения не выпускались.

Проверки исправлений замечаний review: полный прогон — 757 тестов OK
(11 пропущены на macOS); `compileall` и `git diff --check` прошли.
CI, повторный review и test deploy исправлений проверяются отдельно.
